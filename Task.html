Literals

Java, a Literal is value of boolean, numeric, character, or string data. Any constant value that can be assigned to the variable is called a literal.

Keywords

In Java,keywords are predefined , reserved words that have specific meanings to the Java compiler and cannot be used as identifiers
(e.g., variable names, method names, class names).

Identifiers

An identifier in Java is the name given to Variables, Classes, Methods, Packages, Interfaces, etc.

Arrays

An array is a container object that holds a fixed number of values of a single type. The length of an array is established when the array is created.

methods

A method in Java is a set of instructions that can be called for execution using the method name.

operators

Java operators are special symbols that perform operations on variables or values. These operators are essential in programming as they allow you to manipulate data efficiently.

looping techniques

Loops in programming allow a set of instructions to run multiple times based on a condition. In Java, there are three types of loops, each with its own syntax and method of checking the condition, but fundamentally, they all serve the same purpose.
